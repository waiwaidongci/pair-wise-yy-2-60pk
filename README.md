# 赛鸽血统环号登记站

运行：

```bash
npm start
```

访问 `http://localhost:3024`。支持档案、血统查询、转让、归巢成绩记录，以及遗传病筛查检测审核。

## 遗传病筛查检测审核

- 每羽按检测项目记录**结论**（阴性 / 携带者 / 患病）、**样本编号**和**报告日**。
- 同一项目只认**最新有效报告**；被更正或作废的旧报告留档可查，不参与判定。
- 配组审核：双方同一项目均为携带者、或任一方患病，**禁止配组**。
- 已配上的配对在报告变动后**立即冻结**，保留原配对关系、冻结时间和原因；结论更正后自动重算，阻断解除的恢复配组。
- 后代风险提示按双亲最新有效结论实时推算（已有鸽只看父母，配对看两亲本）。
- 页面可查看每羽鸽的**适用种鸽**、**阻断原因**和完整**检测历史**。

## 代码结构（判定 / 档案 / 页面分离）

- `src/genetics.js` — 判定：有效报告选取、配组阻断判定、后代风险评估、适用种鸽
- `src/store.js` — 档案：数据读写与迁移、报告登记/更正/作废、配对登记与冻结重算
- `src/page.js` — 页面
- `server.js` — 路由接线

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/pigeons` | 鸽只列表（附各项目有效结论） |
| GET | `/api/pigeons/:ring/genetics` | 有效结论、检测历史、后代风险提示 |
| GET | `/api/pigeons/:ring/eligible` | 适用种鸽及阻断原因 |
| POST | `/api/pigeons/:ring/reports` | 登记检测报告 |
| POST | `/api/reports/:id/correct` | 更正结论（旧报告留档，按新结论重算） |
| POST | `/api/reports/:id/revoke` | 作废报告（按剩余有效报告重算） |
| GET | `/api/pairs` | 配对列表（状态、阻断原因、后代风险） |
| POST | `/api/pairs` | 登记配组（判定不通过返回 409 及原因） |

数据文件默认为 `data/pigeons.json`，可用环境变量 `DB_PATH` 指定其他路径，`PORT` 指定端口。
